    What should the agent do?

    It works in its own folder, with no network for shell commands. Every step is written to a log first, so you can leave, come back, branch from any step, or resume after a crash.

      Routines

      A routine starts a task on its own: on a schedule, when files arrive in its folder, or when another program calls its webhook. Steps that need approval wait under Approvals; if nobody answers in time, the step does not run.

        Approvals

        Steps an agent stopped at until someone decides. Runs started by a routine skip the step if nobody answers in time.

          Standing rules

          "Always allow" on a step that asks every time adds a rule here. Rules never override the check on what a run has already read and accessed.

            Memory

            Facts the agent keeps between tasks. Each one shows where it came from. Something the agent saved after reading untrusted content (an email, a web page) stays unreviewed until you keep it: until then, any task that sees it is treated as having read untrusted content too.
